# 缓存雨（cache-rain）

pi-web-ui 插件，配合 pi 扩展 [`cache-mode`](../cache-mode/README.md) 使用。

- 输入框旁加一个「缓存」下拉：☀ 日常 1h / ☔ 集中 5m / 关闭。改的是 `~/.pi/agent/cache-mode.json`，和 `/cache-mode` 命令是同一个开关。
- **集中模式下，整个页面开始下雨。** 梗出自《飙马野郎》布莱克摩尔的替身 Catch the Rainbow：用雨滴堵住致命伤，雨一停就会死。雨还在下，缓存就还活着；右上角牌子显示倒计时和『雨停之後，我就會死。』
  - 生成中：雨最大，『在這暴風雨停息之前。』
  - 最后 60 秒：雨变小，牌子变红，旁边冒出「ゴゴゴ」；屏幕下方轮流浮出独白：『即便知曉暴風雨停止之後自己將迎來死亡』『只要擁有想要挽回什麼的【覺悟】』『死亡也沒什麼好怕的了』『因為【覺悟】能夠驅散【絕望】！！！』
  - 倒计时归零：雨停，大字逐字浮出『暴雨結束之時』→『就是我的死期』，再滑出 To Be Continued。
  - 赶在最后 60 秒里续上了：彩虹 +「Catch the Rainbow！」。
  - 过期后又发了消息：「すいませェん……」雨又下起來了（这时缓存已经整段重写过）。
- 默认只对当前正在看的 Magpie Claude 对话生效，匹配规则由 `cache-mode.json` 的 `provider` / `modelPattern` 决定。切到非匹配模型或没有对话时，直接把全局模式改为「关闭」，宿主下拉只保留关闭选项，服务端也会拒绝开启。切回匹配模型后恢复三个选项，但保持关闭，需要手动选择 5m / 1h。所有标签页共享同一份模式，不保留隐藏的历史选择。
- 日常模式和关闭时不显示雨幕。
- 牌子点一下可以收起或展开。系统开了「减少动态效果」时不下雨，只显示牌子。
- 插件页里有两个预览按钮：「暴雨結束之時」（独白 + 雨停）和「Catch the Rainbow」（中途续上）。

## 安装

```sh
pi-web-ui install /path/to/pi-plugins/plugins/cache-rain
```

刷新浏览器生效。权限：`ui`、`http`。没有配置项。

## 测试

```sh
node --test plugins/cache-rain/tests/server.test.mjs
```
